# java_book

## Notiz: Erste Erklärung von `equals`

- Erste Stelle im Buch: `src/records.md`, Abschnitt „Arbeiten mit Objekten“
  (Zeilen 99–106): `firstApple.equals(secondApple)`.
- Dort steht auch die Begründung: `==` prüft bei Objekten nur Identität
  (dasselbe Objekt), nicht inhaltliche Gleichheit.
- Davor (`datentypen.md`, `booleans.md` usw.) wird nur `==` verwendet.
- Spätere Stellen bauen darauf auf: `src/datentypen_2.md` (allgemein
  primitiv vs. Objekt) und `src/nullwerte.md` (`NullPointerException`
  bei `equals` auf `null`).
