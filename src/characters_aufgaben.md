# Aufgaben: Characters

## Übungen

Bearbeite die folgenden Aufgaben in den ausführbaren Java-Blöcken.

### 1. Vorhersage → Ausführen

Schreibe zuerst das Ergebnis auf. Führe dann den Code aus und überprüfe deine Vermutung.

```java, java-exec
'a'
```

### 2. Vorhersage → Ausführen

Schreibe zuerst auf, ob du einen Wert oder einen Fehler erwartest. Führe den Code danach aus und erkläre die Fehlermeldung.

```java, java-exec
'a' + 'b'
```

### 3. Verändere die Eingabe

Ändere nur ein Zeichen, sodass kein Fehler mehr entsteht, sondern der String `"ab"` herauskommt.

```java, java-exec
'a' + 'b'
```

### 4. Ergänze die Lücke

Ergänze die Lücke, sodass `greeting` den String `"hi!"` enthält.

```java, java-exec
var greeting = "hi" + ____;
greeting
```

### 5. Prüfe deine Idee

Sage voraus, was herauskommt, bevor du den Code ausführst. Erkläre, warum das Ergebnis ein *String* und kein *Character* ist.

```java, java-exec
"a" + ' '
```
