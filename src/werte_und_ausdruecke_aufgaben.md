## Übungen

Bearbeite die folgenden Aufgaben in den ausführbaren Java-Blöcken.

### 1. Vorhersage → Ausführen

Schreibe zuerst das Ergebnis auf. Führe dann den Code aus und überprüfe deine Vermutung.

```java, java-exec
5 - 2 * 3
```

### 2. Verändere die Eingabe

Ändere genau eine Zahl, damit der Ausdruck den Wert `20` hat.

```java, java-exec
2 + 3 * 4
```

### 3. Ergänze die Lücken

Setze Klammern ein, damit der Ausdruck den Wert `25` hat.

```java, java-exec
3 + 2 * 5
```

### 4. Fehler finden und reparieren

Entferne genau ein Zeichen, sodass der Ausdruck gültig ist und den Wert `1` hat.

```java, java-exec
1 + * 1
```

### 5. Prüfe deine Idee

Vergleiche die beiden Ausdrücke und erkläre, warum sie unterschiedliche Ergebnisse haben.

```java, java-exec
(2 + 3) * 4
```

```java, java-exec
2 + 3 * 4
```

### 6. Vorhersage → Ausführen (mehrere Schritte)

Der Ausdruck enthält mehrere Rechenschritte. Berechne ihn zuerst per Hand und notiere jeden Zwischenschritt. Überprüfe dein Ergebnis danach im Block.

```java, java-exec
2 + 3 * (4 - 1) * 2
```

### 7. Ergänze die Lücken (zwei Klammerpaare)

Setze zwei Klammerpaare so ein, dass der Ausdruck den Wert `15` hat.

```java, java-exec
2 + 3 * 4 - 1
```

### 8. Fehler finden und reparieren (fehlende Klammer)

Der Ausdruck hat einen Syntaxfehler, weil eine Klammer fehlt. Ergänze die fehlende Klammer, sodass der Ausdruck gültig ist und den Wert `20` hat.

```java, java-exec
4 * (2 + 3
```
