## Übungen

Bearbeite die folgenden Aufgaben in den ausführbaren Java-Blöcken.

### 1. Vorhersage → Ausführen

Schreibe zuerst das Ergebnis auf. Führe dann den Code aus und überprüfe deine Vermutung.

```java, java-exec
"hello" + "world"
```

### 2. Verändere die Eingabe

Ändere nur die Zahl, sodass der String genau fünfmal wiederholt wird.

```java, java-exec
"ha".repeat(3)
```

### 3. Fehler finden und reparieren

Der Code gibt nicht den in `bat` gespeicherten String aus, sondern den Text `"bat"`. Repariere den Ausdruck, sodass der Wert der Variablen `bat` verwendet wird.

```java, java-exec
var bat = "^._.^";
"A bat looks like this: " + "bat"
```

### 4. Ergänze die Lücke

Ergänze die Lücke, sodass `combined` aus `greeting`, einem Leerzeichen und `farewell` besteht (zum Beispiel `"hello goodbye"`).

```java, java-exec
var greeting = "hello";
var farewell = "goodbye";
var combined = ____;
combined
```

### 5. Prüfe deine Idee

Führe den Code aus und erkläre die Fehlermeldung. Repariere den Code danach so, dass er den String `"looks"` ausgibt.

```java, java-exec
looks
```
