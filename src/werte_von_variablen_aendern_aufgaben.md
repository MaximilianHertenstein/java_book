## Übungen

Bearbeite die folgenden Aufgaben in den ausführbaren Java-Blöcken.

### 1. Vorhersage → Ausführen

Schreibe zuerst das Ergebnis auf. Führe dann den Code aus und überprüfe deine Vermutung.

```java, java-exec
int a = 3;
a = a + 2;
a
```

### 2. Prüfe deine Idee

Sage voraus, welchen Wert `y` am Ende hat, und erkläre warum.

```java, java-exec
int x = 4;
int y = x;
x = 9;
y
```

### 3. Verändere die Eingabe

Ändere nur den Startwert von `a`, sodass `a` am Ende den Wert `20` hat.

```java, java-exec
int a = 5;
a = 2 * a;
a
```

### 4. Fehler finden und reparieren

Repariere den doppelten Operator.

```java, java-exec
int count = 0;
count = count + + 1;
count
```

### 5. Ergänze die Lücke

Ergänze die Lücke, sodass `b` am Ende genau doppelt so groß wie `a` ist.

```java, java-exec
int a = 6;
int b = ____;
b
```
