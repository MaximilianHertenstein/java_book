## Übungen

Bearbeite die folgenden Aufgaben in den ausführbaren Java-Blöcken.

### 1. Vorhersage → Ausführen

Schreibe zuerst das Ergebnis auf. Führe dann den Code aus und überprüfe deine Vermutung.

```java, java-exec
7.0 / 2
```

### 2. Verändere die Eingabe

Ändere nur eine Zahl, sodass das Ergebnis genau `5.0` ist.

```java, java-exec
10 / 2
```

### 3. Ergänze die Lücke

Ergänze die Lücke, sodass `numberInt` die abgerundete Ganzzahl von `numberFloat` enthält.

```java, java-exec
double numberFloat = 7.9;
int numberInt = ____;
numberInt
```

### 4. Fehler finden und reparieren

Der Code erzeugt einen Fehler. Ergänze die fehlende Typumwandlung.

```java, java-exec
double price = 19.99;
String count = "3";
price * count
```

### 5. Prüfe deine Idee

Sage voraus, ob das Ergebnis exakt ist, bevor du ausführst.

```java, java-exec
0.1 + 0.2
```
