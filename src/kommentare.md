# Kommentare


Hinter der Zeichenkombination `//` muss kein korrekter Java-Code stehen.

```java, java-exec
// Umrechnung von Fuß in Zoll
int feetToInch(int lengthInFeet) {
    return 12 * lengthInFeet;
}
```

Dies kann genutzt werden, um den Code zu erklären und zu strukturieren.
